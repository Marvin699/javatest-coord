# 项目地图填写指南（给开发侧 AI 看）

你的任务：扫描目标项目源码，填写本目录三件套。
这是「半自动」流程：脚手架由 `aip map-init` 生成，内容由你产出，最后由人类审核提交。

## 三件套

| 文件 | 内容 | 谁读 |
|---|---|---|
| architecture.md | 模块结构、关键链路、技术栈、约定 | 客户 AI + 开发侧 AI |
| api.json | 接口清单（method / path / desc / module） | 客户 AI 定位线索用 |
| schema.json | 数据表清单（name / fields / desc） | 客户 AI 判断动不动数据库 |

## 铁律

1. **只写真实存在的东西**：每个路径、每个接口、每张表都必须是你在代码里亲眼看到的，禁止推测补全
2. **脱敏**：不写内网地址、密钥、客户真实数据；用业务语言描述，不堆实现细节
3. **拿不准的标注 `（未确认）`**，留给人类处理
4. **精简**：全目录控制在 200 行以内——这是给客户 AI 的「索引」，不是文档全集，宁可少写不可写错

## 填完后

提醒人类 review 三个文件的 diff，确认无敏感信息再 push。
此地图会随每次 PR 增量更新（改了模块/接口/表就顺手改地图）。
